# 진료비한눈 (medicalpricehannun)

건강보험심사평가원 공개 의료기관 정보와 비급여 가격을 지도에서 비교하기 위한 웹앱입니다.

## 현황
초기 웹 UI 구축 단계입니다. 공식 API 키, 의료기관 데이터, 비급여 가격 수집은 아직 연결되지 않았습니다. 실제 가격인 것처럼 샘플 데이터를 표시하지 않습니다.

## 데이터 원칙
- 공개 신고가격, 건강보험 약가, 실제 결제가격을 혼동하지 않습니다.
- 기관·항목·가격·기준일·원문 출처를 함께 보존합니다.
- 의원급 비급여 일괄 제공 경로 및 재배포 조건을 검증한 뒤 수집합니다.
- 비밀키는 GitHub Secrets에만 저장합니다.

## 예정 작업
1. 심평원 병원·약국 정보 API 및 공개 CSV 검증
2. 비급여 API 기관·항목 코드 확인
3. JSON.gz 지역별 분할 수집
4. 지도 마커·가격 필터·검색 연동
5. 수집 상태 및 GitHub Actions 모니터링
